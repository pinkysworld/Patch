Patch Studio Offline IDE

offline-ide-v0.2 is the rolling local Studio channel. The packaged IDE is the real Patch Studio, not a separate editor. It starts a local loopback server and opens the installed browser, preserving ES modules, service-worker behavior, project v4 resources, recovery and the source-backed Designer without bundling Chromium. Platform release packages include their own Node runtime.

Current native Window surface

The current desktop line is Native GUI IR 1.8 / payload v18 / runtime v1.9. It adds ImageList metadata and Button image list.item transport to the previous PaintBox image line. The current no-token browser build and the offline linker both import native-current-contract.js, so they cannot silently drift to different product versions.

  • Forms and layout: source-backed Forms, Anchor/Dock and native control positioning.
  • Data and choices: Table/Grid, multi-select ListBox, Menu state/shortcuts, TreeView and Slider.
  • Chrome and structure: Panel, Timer and StatusBar.
  • Graphics: Picture, Shape and PaintBox with clear, line, rectangle, ellipse, text and bounded PNG/JPEG draw image.
  • Images on controls: ImageList plus Button image list.item on Win32, AppKit and GTK.
  • Still fail-closed: native application/window icon packaging and unsupported image formats or display properties.

PictureBox note: current desktop decoding supports bounded project-resource and data-URI PNG/JPEG images through Win32/WIC, AppKit/NSImage and GTK/GdkPixbuf under native-picture-formats/1.0. This is not a claim of complete portable image-source rendering across every project image type or display property.

Workshop Desk acceptance example

examples/workshop-desk.patch is the broad current Ready example. It combines three Forms with Text, Button, Input, Checkbox, Radio, ComboBox, ListBox, Slider, Table, TreeView, Tabs, Picture, ImageList/Button image, Panel, Shape, PaintBox, StatusBar and Timer. The ImageList uses a bounded static inline PNG so the source remains self-contained. The offline compiler matrix links that example on Windows, Linux, Apple Silicon macOS and Intel macOS.

Versioned compatibility

Native GUI IR 1.7 / payload v17 / runtime v1.8 remains the PaintBox image compatibility line. Native GUI IR 1.6 / payload v16 / runtime v1.7 remains the PaintBox Stage 1 line. Native GUI IR 1.5 / payload v15 / runtime v1.6 remains the Shape line. Native GUI IR 1.4 / payload v14 / runtime v1.5 remains the Chrome line. Native GUI IR 1.3 / payload v13 / runtime v1.4 remains the Slider-capable compatibility line. Native GUI IR 1.2 / payload v12 / runtime v1.3 remains the frozen TreeView line. Older contracts are never silently reinterpreted.

Verify a compiler download

# Linux or macOS with sha256sum
sha256sum -c SHA256SUMS

# macOS built-in
shasum -a 256 patch-macos-arm64

# Windows PowerShell
Get-FileHash .\patch-windows-x64.exe -Algorithm SHA256

SHA-256 verifies release-byte consistency. Development artifacts remain unsigned unless a release explicitly states otherwise.
