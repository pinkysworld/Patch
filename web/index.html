Transient value

Input editing supplies event-local value; the control does not write persistent Patch state.

Explicit commit

Source persists input only through ordinary semantic change. Window preflight supports button clicked and input changed.

Build formats & boundariesNo silent fallbacks

Direct Wasm + portable C99

Direct Wasm lowers the supported numeric Console subset. Raw direct Wasm uses Patch's small host ABI and is not yet a standalone WASI command. Portable C99 is compile/run tested on Linux, macOS and FreeBSD 15.1.

Window targets

Window Web Apps use the generated browser runtime; Windows/macOS/Linux Window packages use the generated desktop player. They are standalone but not yet native AppKit/Win32/GTK widget lowering.
