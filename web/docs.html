Native applications and release engineering

Current Ready/offline Windows, macOS and Linux use Native GUI IR 1.3 / payload v13 / runtime v1.4. Slider is native through TRACKBAR, NSSlider and GtkScale. The v12/v1.3 TreeView line remains frozen for compatibility. Product JavaScript imports those two live contracts through native-current-contract.js and native-frozen-contract.js. The public Studio site ships those contracts and their snapshots; retired v07–v11 copies stay test-only historical evidence. Unversioned native-gui-ir.js and unversioned sealed C++ templates remain labeled IR 0.7 / payload v6 include-chain bases and do not gate Ready or Pages.
