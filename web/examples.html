Showcases: exhaustive Studio, working app and native boundary

Patch Studio Showcase

The canonical multi-file Project-v4 acceptance project is the exhaustive Studio feature explorer. Its reviewer profile gives the controls one coherent context without artificial scoring. It covers every Component Registry 0.10 component, the current source-backed R4 presets and advanced Table columns, including passive ProgressBar via # @slider-mode progress, project resources, menus and result dialogs, and its full Web target builds without stripping features. It is selectable directly in hosted and Offline Studio.

Workshop Desk

Workshop Desk is the working Project-v4 application. Its seven Forms share one real ticket workflow: queue selection loads state, parts change the working item, quotes recalculate from current inputs without compounding, customer saves and reorders persist into Things, and diagnostics distinguish runs from timer pulses. Project resources drive the app icon, Pictures, PaintBox and ImageList-backed buttons.

Target boundaries

Showcase is exhaustive, Workshop is a coherent application, and workshop-desk-native.patch is the intentionally narrower Current Ready desktop fixture. Separating those roles keeps unsupported native semantics fail-closed instead of weakening the richer examples.
