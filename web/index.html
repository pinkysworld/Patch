Covered

Safe-integer RangeExpr binding, direct quantitative add/remove, sequence, literal/static repeat, formal GuardExpr branches over exact recipe parameters, complete selected exact trace, both-arm callee signature coverage and caller signature import.

Still outside

State-dependent guard variables, nested/transitive recipe calls inside the certified body, dynamic repeats, arbitrary expressions outside the formal fragments, complete transitive call trees and production JavaScript/direct-Wasm call equivalence. Patch is not an end-to-end verified compiler.

Build formats & boundariesNo silent fallbacks

Direct Wasm + portable C99

Direct Wasm lowers the supported numeric Console subset. Raw direct Wasm uses Patch's small host ABI and is not yet a standalone WASI command. Portable C99 is compile/run tested on Linux, macOS and FreeBSD 15.1.

Window targets

Window Web Apps use the generated browser runtime; Windows/macOS/Linux ready Window downloads use a sandboxed Electron desktop player with a checked Patch source payload. They are standalone packages but not yet native AppKit/Win32/GTK widget lowering.
