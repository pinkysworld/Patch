Patch Studio help

Build something without fighting the IDE.

Quick help for the workflows that matter most: editing, visual form design, project recovery and desktop builds.

Run   Ctrl/Cmd + Enter
Build Ctrl/Cmd + Shift + Enter

Ctrl/Cmd/Shift-click: add/remove selection
Arrow keys: move primary or selected group

Design a Window app

1

Choose Window as the project type or open the Window example.

2

Use the Designer palette to add Text, Button, Input, Checkbox, Radio, Combo, ListBox, Table or Tabs controls.

3

Select a control to move it. Drag it to snap nearby edges and centers to visible alignment guides, hold Alt while dragging to bypass snapping, use the arrow keys for 1 px source-backed positioning, hold Shift for 10 px keyboard steps, or edit X/Y/W/H in Properties. Drag its resize grip to change its size.

4

Use Ctrl-click, Cmd-click or Shift-click to add or remove controls from the current selection. The solid control is the primary control. Drag or keyboard-move that primary control to move the selected group together. The Left, Top, H center and V center commands align the other selected controls to the primary control and write the resulting positions back into Patch source.

5

Choose an Anchor or Dock policy in Properties when a control should react to Form resizing. Studio writes that policy visibly into source as a # @layout ... directive. Anchor supports left/right/top/bottom combinations; Dock supports top, bottom, left, right and fill.

6

Resize the form itself from the grip in the form's lower-right corner. Forms may grow beyond the visible Designer width; use the Designer scrollbars to reach the rest. The same source-backed Anchor/Dock policy is also honored when a built Standalone Web, direct native AOT or token-free Ready app is resized at runtime on Windows, macOS or Linux.

Table / Grid

Table data is written directly in Patch source. The header declares named columns and each indented row supplies exactly one value per column.

window "People" as main size 520, 320:
  table "Name", "Role" as people at 24, 64 size 440, 180:
    row "Ada", "Engineer"
    row "Grace", "Scientist"

when people changed:
  show value

The source-backed Stage 1 Designer can add, select, move, resize, rename and remove a Table while preserving its row lines. Stage 2a adds row selection to the shared Window event contract and Standalone Web. changed exposes the selected row only as transient value, represented as a Patch list of display strings. Selecting a row does not create persistent Patch state or Change History by itself.

Standalone Web supports mouse and keyboard row selection and keeps aria-selected as renderer-local UI state. Studio App-preview event dispatch and direct native Win32/AppKit/GTK Table widgets are separate follow-ups; native Table lowering still fails closed rather than silently dropping the control.

Projects and recovery

Patch Studio autosaves locally. Project bundles also preserve the project type and build configuration. Use Export for a portable .patchproject file, Import to restore one, and Recovery to manage local snapshots.

If an import or restore goes wrong

The Studio protects the current state with a recovery snapshot before replacement. Corrupt canonical storage is quarantined rather than silently trusted.

Build targets

Standalone Web AppSingle HTML output for Console or Window projects. Desktop appsReady/no-token Windows, macOS and Linux paths plus local and cloud build options. Offline compiler downloadsRun, compile and locally link Patch apps from Windows, macOS, Linux or FreeBSD without opening Studio.

GitHub tokens are only used by the optional cloud/AOT path and are not saved by Patch Studio. The normal ready-app paths and the downloaded offline compiler do not require a token.

Offline compiler

After downloading the compiler for your platform, use patch check app.patch, patch run app.patch, patch build ... or patch link app.patch --out App. Windows, macOS and Linux compiler downloads include responsive native runtime v0.9 templates, so locally linked Window apps preserve Anchor/Dock behavior without a cloud build. FreeBSD uses the portable C99 linker path and requires local Node plus cc; native FreeBSD GUI linking is not yet claimed.

Troubleshooting

The website still looks old

Patch Studio uses content-addressed web revisions. A browser session from before that update mechanism may need one reload, or an installed PWA may need to be closed and reopened once. Future site revisions should then update automatically.

A control disappeared below the form

The Designer scroll area supports vertical and horizontal scrolling, and newly added controls are revealed automatically. Controls that extend beyond a form also grow the form to fit.

I need support information

Use Copy diagnostics or Report. The Studio report remains local and omits source code while including version, target, compiler status and privacy-redacted errors.
