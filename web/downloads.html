Run locally

patch run program.patch executes Patch source locally. patch check validates it without producing an application.

Compile locally

patch build retains the existing portable, WebAssembly, C99 and standalone Web targets without requiring Patch Studio.

Link locally

patch link program.patch builds a ready application for the current OS when the project fits the supported native surface. Windows/macOS/Linux Window apps use Native GUI IR 0.8 sealed as payload v9 into runtime v1.0, including Table/Grid and runtime-responsive Anchor/Dock layout; Console linking uses the platform's supported local runtime path.

Table / Grid and offline linking

Table/Grid is supported by the language, Designer, Studio App preview, Standalone Web and direct native AOT backend 0.9.

The downloadable Windows, macOS and Linux compiler now supports Table through patch link. The compiler embeds the same sealed runtime v1.0 contract used by token-free Ready apps. CI links the same Table source through the ordinary offline CLI and starts the resulting .exe, AppKit .app and GTK executable, checking payload v9, real columns/rows and native row-selection dispatch. FreeBSD remains Console-only.

Platform notes

Windows

The x64 compiler can link supported Window projects, including Table/Grid, into a single native Win32 .exe and Console projects into a standalone executable. Responsive controls reflow through the native WM_SIZE path.

macOS Apple Silicon

The Apple Silicon download is one standalone compiler binary. patch link writes supported responsive AppKit .app bundles, including multi-column Table/Grid. Development compiler builds are ad-hoc signed, not Developer ID notarized.

macOS Intel

The Intel download is a portable tar.gz kit because Node's SEA path is not currently reliable on macOS x64. It already contains an Intel Node runtime, so no Node installation is required. Console linking creates a portable .app containing direct Patch Wasm and the embedded Node runtime; supported Window apps use the AppKit runtime v1.0 with payload v9 Table/Grid and responsive layout.

Linux

The x64 compiler links supported Window projects, including Table/Grid, against the embedded GTK3 runtime v1.0. The resulting GUI executable still expects the target system's normal compatible GTK3/system libraries.

FreeBSD

FreeBSD currently supports Console linking through Patch's portable C99 backend. The FreeBSD kit is offline after download but requires a locally installed Node runtime and C compiler. Native FreeBSD Window/GUI linking is not claimed yet.
