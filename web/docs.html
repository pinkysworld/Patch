Start here

Patch Studio edits ordinary Patch source. The visual Designer does not maintain a second hidden form model.

Hosted Studio

  1. Open Patch Studio.
  2. Edit the sample source and press Run.
  3. Switch to Designer for a Window application.
  4. Add controls from the searchable Component Palette and edit properties/events in Object Inspector.

Offline path

The rolling offline-studio-v0.2 channel publishes Windows x64/ARM64, Linux x64/ARM64, macOS Apple Silicon, a macOS Intel embedded-runtime kit, and a portable Node 18+ bundle that is also exercised on FreeBSD 15 x64.

Stage 2 R0.1 has the authenticated patch-offline-build-bridge/0.1 in source. Installed host-native Build UI/toolchain integration is not complete yet, so use the standalone Offline Compiler for native linking today.

Language guide

Values and state

Current persistent state includes number, text, boolean, list and finite Thing values.

Explicit change

Existing persistent state mutates through semantic change blocks rather than hidden assignment.

Control flow

if/else and repeat structure execution while nested mutation stays explicit.

Recipes

make declares reusable behavior and do invokes it. Change capabilities can constrain semantic authority.

GUI applications and Patch Studio

Patch Studio is a source-backed RAD environment. Editor, Designer, Object Inspector, Project Tree, Resource Manager and component tools operate on the same project source.

Current RAD workflow

  1. Create or select a Form.
  2. Add a control from the Component Palette.
  3. Move/resize it or edit geometry directly in source.
  4. Use Object Inspector for source-backed properties and events.
  5. Use Undo/Redo, Copy/Cut/Paste, Duplicate, Delete and layout operations through shared Designer command paths.
  6. Press Run and inspect diagnostics/artifacts.

Current component families

Text, Button, Input, Checkbox, Radio, ComboBox, ListBox, Slider, Table, TreeView, Tabs, Panel, Picture, Shape, PaintBox, StatusBar, Timer, ImageList and Menu are available through the source-backed authoring surface. Target parity stays explicit and conservative.

Open the component capability matrix

Copy/Cut/Paste: single-control transfer works across Forms and projects, preserves contiguous layout/tab/lock metadata, validates external clipboard JSON semantically, remaps colliding IDs/events and supports paste into an empty active Form.
