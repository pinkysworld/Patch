Run locally

patch run program.patch executes Patch source locally. patch check validates it without producing an application.

Compile locally

patch build retains the existing portable, WebAssembly, C99 and standalone Web targets without requiring Patch Studio.

Link locally

patch link program.patch builds a ready application for the current OS when the project fits the current sealed-runtime surface. Native Window apps use payload v8/runtime v0.9, including runtime-responsive Anchor/Dock layout; Console linking uses the platform's supported local runtime path.

Table / Grid and offline linking

Patch Table/Grid is available in the language, Designer and Standalone Web. Direct native AOT backend v0.9 also has real Win32, AppKit and GTK3 Table widgets with CI compile/runtime smokes.

The current downloadable compiler does not yet claim Table support for patch link. Offline Window linking still seals the Native GUI IR 0.7 control surface into payload v8/runtime v0.9. A Table project must therefore fail closed instead of silently producing an incomplete native app. This download page will only advertise offline Table linking after the sealed payload/runtime consumer is upgraded and smoke-tested.

Platform notes

Windows

The x64 compiler can link supported Window projects into a single native Win32 .exe and Console projects into a standalone executable. Responsive controls reflow through the native WM_SIZE path.

macOS Apple Silicon

The Apple Silicon download is one standalone compiler binary. patch link writes supported responsive AppKit .app bundles. Development compiler builds are ad-hoc signed, not Developer ID notarized.

macOS Intel

The Intel download is a portable tar.gz kit because Node's SEA path is not currently reliable on macOS x64. It already contains an Intel Node runtime, so no Node installation is required. Console linking creates a portable .app containing direct Patch Wasm and the embedded Node runtime; supported Window apps use the responsive AppKit v0.9 runtime.

Linux

The x64 compiler links supported Window projects against the embedded responsive GTK3 v0.9 runtime. The resulting GUI executable still expects the target system's normal compatible GTK3/system libraries.

FreeBSD

FreeBSD currently supports Console linking through Patch's portable C99 backend. The FreeBSD kit is offline after download but requires a locally installed Node runtime and C compiler. Native FreeBSD Window/GUI linking is not claimed yet.
