Semantic Change Contracts

Patch infers operation- and magnitude-aware Change Signatures and constrains them with Change Capabilities. The Lean core covers factorization, Change Signature Soundness, policy containment, source/evidence correspondence and integer range-analysis soundness for explicit fragments.

Independent raw-source validation reconstructs the supported Source core and range claims before static certification.

Build formats & boundariesNo silent fallbacks

Direct Wasm + portable C99

Direct Wasm lowers the supported numeric Console subset. Raw direct Wasm uses Patch's small host ABI and is not yet a standalone WASI command. Portable C99 is compile/run tested on Linux, macOS and FreeBSD 15.1.

Window targets

Window Web Apps use the generated browser runtime; Windows/macOS/Linux Window packages use the generated desktop player. They are standalone but are not yet native AppKit, Win32 or GTK widget lowering. FreeBSD Window is not supported yet.
