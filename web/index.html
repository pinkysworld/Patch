Beta.31 call-aware direct-Wasm correspondenceExecuted runtime + independent validation + Lean

Runtime evidence

The existing direct-Wasm backend runs unchanged. Its complete raw transition stream is independently validated; semantic operation identity and recipe scope are reconstructed outside the backend.

GeneratedTransitiveRuntimeCertificate.lean records the runtime-derived effects and trace hash.

Formal check

PatchCallRuntime.lean checks the observed effect list with evalCallTreeStmtEqBool against the exact beta.30 call tree before caller-signature refinement.

Only one unique scoped exact-effect sequence is accepted. Ambiguous repetitions fail closed. Runtime capture, validator correctness and scoped-slice attribution remain proof-free evidence boundaries.

Beta.30 finite transitive exact call trees

PatchCallTree.lean checks nested exact bindings, strict rank decrease, selected guards/repeats/effects and edge-by-edge semantic-signature import for caller → outer → middle → leaf.

Exact beta.31 boundaryNo full compiler claim

Patch is not an end-to-end verified compiler. Parser correctness, JavaScript-to-Wasm lowering, Wasm-engine correctness, runtime capture, independent-validator correctness and scoped-slice attribution remain outside the theorem.
