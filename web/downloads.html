Run locally

patch run program.patch executes Patch source locally. patch check validates it without producing an application.

Compile locally

patch build retains the existing portable, WebAssembly, C99 and standalone Web targets without requiring Patch Studio.

Link locally

patch link program.patch builds a ready application for the current OS. Console and supported Window apps use the same checked runtime-sealing approach as the no-token Patch Studio path.

Platform notes

Windows

The x64 compiler can link supported Window projects into a single native Win32 .exe and Console projects into a standalone executable.

macOS

Apple Silicon and Intel compiler downloads are provided separately. patch link writes a normal .app bundle. Development builds are ad-hoc signed, not Developer ID notarized.

Linux

The x64 compiler links supported Window projects against the embedded GTK3 runtime. The resulting GUI executable still expects the target system's normal compatible GTK3/system libraries.

FreeBSD

FreeBSD currently supports Console linking through Patch's portable C99 backend. The FreeBSD kit is offline after download but requires a locally installed Node runtime and C compiler. Native FreeBSD Window/GUI linking is not claimed yet.
