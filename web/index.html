Beta.30 finite transitive exact call treesNested binding + rank + signature import

Recursive exact execution

PatchCallTree.lean preserves beta.29 bodies as call-free leaves and recursively re-evaluates every nested RangeExpr argument into a new exact BindingList. It reuses exact GuardExpr, static-repeat and quantitative-effect semantics.

GeneratedTransitiveCallBodyCertificate.lean exercises caller → outer → middle → leaf and checks a depth-2 selected trace.

Finite semantic discipline

Lean checks strict beta.25 rank decrease on the outer certified edge and every nested edge. Each nested body is covered by its own callee signature before the trace is imported one SignatureCovers edge at a time into the caller.

The supported beta.30 example yields exact score +4 and coins +3 effects. Root-program certification, cycles, dynamic repeat and production JavaScript/direct-Wasm call equivalence remain outside the claim.

Exact beta.30 boundaryNo overclaim

Covered

Finite rank-decreasing calls, safe-integer RangeExpr binding, direct quantitative changes, sequence, literal/static repeat, exact formal GuardExpr branches, complete selected transitive traces and edge-by-edge signature import.

Still outside

Root-program certification, recursion/cycles, state-dependent exact guards, dynamic repeats, returns, floating-point/full-language semantics and production JavaScript/direct-Wasm call equivalence. Patch is not an end-to-end verified compiler.

Direct Wasm + portable C99

Direct Wasm lowers the supported numeric Console subset. Raw direct Wasm uses Patch's small host ABI and is not yet a standalone WASI command. Portable C99 is compile/run tested on Linux, macOS and FreeBSD 15.1.

Window targets

Window Web Apps use the generated browser runtime; Windows/macOS/Linux ready Window downloads use a sandboxed Electron desktop player with a checked Patch source payload. They are standalone packages but not yet native AppKit/Win32/portable Unix widget lowering.
