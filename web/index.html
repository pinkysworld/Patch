Beta.32 invocation-frame correspondenceExecuted runtime + independent frames + Lean

Runtime evidence

The direct-Wasm backend runs unchanged and emits no call-enter/call-exit markers. The independent Change-IR validator reconstructs concrete invocation-frame identities, exact parameter bindings, parent/depth information and active frame stacks while validating the complete raw transition trace.

GeneratedTransitiveRuntimeCertificate.lean and GeneratedRepeatedTransitiveRuntimeCertificate.lean record single and repeated-call evidence.

Formal check

PatchCallRuntime.lean re-evaluates the frame-selected observed effects using evalCallTreeStmtEqBool. The generated beta.32 certificate also checks the runtime frame BindingList equals the beta.30 exact callee binding.

Repeated identical calls can therefore be certified separately. Runtime capture and independent-validator/frame-reconstruction correctness remain proof-free boundaries.

Exact beta.32 boundaryNo full compiler claim

Patch is not an end-to-end verified compiler. Parser/extractor correctness, JavaScript-to-Wasm lowering, Wasm-engine correctness, runtime capture and independent invocation-frame reconstruction remain outside Lean.
