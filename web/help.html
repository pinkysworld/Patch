Build something without fighting the IDE.

Quick help for the workflows that matter most: editing, visual form design, project recovery, verified Ready builds and local downloads.

Run   Ctrl/Cmd + Enter
Build Ctrl/Cmd + Shift + Enter

Designer: select, drag, resize
Ctrl/Cmd/Shift-click: add/remove selection
Arrow keys: move primary or selected group
Shift + Arrow: move 10 px
Alt while dragging: bypass snap

Design a Window app

1

Choose Window as the project type or open the Window example.

2

Use the Designer palette to add Text, Button, Input, Checkbox, Radio, Combo, ListBox, Table or Tabs controls.

3

Select a control to move it. Drag it to snap nearby edges and centers to visible alignment guides, hold Alt while dragging to bypass snapping, use the arrow keys for 1 px source-backed positioning, hold Shift for 10 px keyboard steps, or edit X/Y/W/H in Properties. Drag its resize grip to change its size.

4

Use Ctrl-click, Cmd-click or Shift-click to add or remove controls from the current selection. The solid control is the primary control. Drag or keyboard-move that primary control to move the selected group together. The Left, Top, H center and V center commands align the other selected controls to the primary control and write the resulting positions back into Patch source.

5

Choose an Anchor or Dock policy in Properties when a control should react to Form resizing. Studio writes that policy visibly into source as a # @layout ... directive. Anchor supports left/right/top/bottom combinations; Dock supports top, bottom, left, right and fill.

6

Resize the form itself from the grip in the form's lower-right corner. Forms may grow beyond the visible Designer width; use the Designer scrollbars to reach the rest. The same source-backed Anchor/Dock policy is honored by Standalone Web, direct native AOT, token-free Ready apps and supported offline-linked Window apps on Windows, macOS and Linux.

ListBox: single or multi-select

A ListBox bound to create text is the single-select control. Its changed event receives a text value.

A ListBox bound to create list is multi-select in Patch Studio App Preview, Standalone Window Web, direct Win32/AppKit/GTK AOT and current token-free Ready/offline Windows, macOS and Linux apps. Its changed event receives a copied list of selected strings.

create list fruits = ["Banana", "Mango"]

window "Fruit Picker":
  listbox "Apple", "Banana", "Cherry", "Mango" as fruits

when fruits changed:
  change fruits:
    set = value

Selection is transient until the handler executes change. If the handler only inspects or shows value, persistent fruits remains unchanged. Native selection therefore follows the same explicit-mutation rule as browser selection.

Current native contract: Native GUI IR 1.1 / direct backend 1.2 for AOT, and sealed payload v10/runtime v1.1 for Ready/offline builds. Payload v9/runtime v1.0 remains a frozen Table-capable compatibility line and is not retroactively widened.

Table / Grid

Table data is written directly in Patch source. The header declares named columns and each indented row supplies exactly one value per column.

window "People" as main size 520, 320:
  table "Name", "Role" as people at 24, 64 size 440, 180:
    row "Ada", "Engineer"
    row "Grace", "Scientist"

when people changed:
  show value

The source-backed Designer can add, select, move, resize, rename and remove a Table while preserving its row lines. The shared Window event contract, Studio App preview and Standalone Web support row selection. changed exposes the selected row only as transient value, represented as a Patch list of display strings. Selecting a row does not create persistent Patch state or Change History by itself.

Direct native AOT Table support uses Native GUI IR 0.8 / backend 0.9. CI compiles and executes real Win32 WC_LISTVIEWW, AppKit NSTableView and GTK3 GtkTreeView Table smokes, including native selection dispatch and responsive layout.

Current token-free Ready apps and offline patch link use sealed payload v10/runtime v1.1 for Window projects on Windows, macOS and Linux. Payload v10 preserves the Table columns/rows, transient row-list event type and Anchor/Dock policy introduced by v9, while adding persistent text-list state for native multi-select ListBox. Payload v9/runtime v1.0 remains the frozen previous Table-capable line.

Projects and recovery

Patch Studio autosaves into the versioned v2 project store. Project bundles preserve the source, project type and build configuration. Use Export for a portable .patchproject file, Import to restore one, and Recovery to manage local snapshots.

Programmatic changes from sample switching and Designer actions use the same shared source/project signals as manual editing. That keeps the canonical v2 state, visual Designer, Change Contract and native-build panel synchronized.

If an import or restore goes wrong

The Studio protects the current state with a recovery snapshot before replacement. Corrupt canonical storage is quarantined rather than silently trusted.

Offline compiler downloadsRun, compile, verify and locally link supported Patch apps from Windows, macOS, Linux or FreeBSD without opening Studio.

GitHub tokens are only used by the optional cloud/AOT path and are not saved by Patch Studio. The normal ready-app paths and the downloaded offline compiler do not require a token.

Ready runtime verification

Before a no-token Windows, macOS or Linux Window build is sealed, Patch Studio verifies the selected native runtime template with SHA-256. The Pages deployment creates a runtime manifest from the SHA-256 digest recorded on the corresponding GitHub Release asset and independently checks the downloaded release bytes. The browser hashes the runtime again before use and stops the build on any mismatch.

Current native GUI Ready assets are the platform runtime-v1.1 releases. Runtime requests are fresh-first while the Studio is online, so an old service-worker cache cannot silently win over a newer deployed runtime. A successfully fetched runtime may still be used as an offline fallback.

This verifies byte consistency for the runtime-template path. It does not turn unsigned development applications into Authenticode-signed or Developer ID-notarized releases.

Offline compiler

After downloading the compiler for your platform, use patch check app.patch, patch run app.patch, patch build ... or patch link app.patch --out App. Windows and Linux downloads, Apple Silicon macOS and the Intel macOS portable kit include native Window runtime v1.1. Supported responsive, Table/Grid and list-backed multi-select ListBox Window apps link locally through sealed payload v10 without a cloud build or GitHub token. FreeBSD uses the portable C99 linker path and requires local Node plus cc; native FreeBSD GUI linking is not yet claimed.

Download SHA256SUMS beside the compiler asset and verify it before first use. The Downloads page includes Linux/macOS and PowerShell examples.

Troubleshooting

The website still looks old

Patch Studio uses content-addressed web revisions. A browser session from before that update mechanism may need one reload, or an installed PWA may need to be closed and reopened once. Future site revisions should then update automatically.

A native build stops with an integrity error

Do not bypass the check. Reload the Studio once while online. If the release asset, deployed manifest and fetched runtime do not agree, Patch intentionally refuses to seal the app.

A list-backed ListBox fails in an older native runtime

Use the current runtime v1.1 / payload v10 path. The frozen payload v9/runtime v1.0 compatibility line predates persistent native list state and intentionally remains fail-closed instead of silently changing multi-select semantics.

A control disappeared below the form

The Designer scroll area supports vertical and horizontal scrolling, and newly added controls are revealed automatically. Controls that extend beyond a form also grow the form to fit.

I need support information

Use Copy diagnostics or Report. The Studio report remains local and omits source code while including version, target, compiler status and privacy-redacted errors.
