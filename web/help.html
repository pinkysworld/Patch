Current contracts

Patch Studio uses project bundle v4, Change IR 0.10 and Native GUI IR 1.4 / payload v14 / runtime v1.5 on the current Ready/offline Windows, macOS and Linux line. Project v1-v3 inputs migrate explicitly.

Projects and resources

Project v4 keeps bounded multi-file Patch source plus explicit image resources. The Resource Manager stores logical ids, project-relative paths, media type, size, SHA-256 and canonical project bytes. Current resource types are PNG, JPEG, WebP and SVG.

picture as logo from "patch-resource:app.logo"

imagelist as toolbar_images size 16, 16:
  image open from "patch-resource:icons.open"

Export, Import and Recovery preserve source and resources together.

Designer and Object Inspector

The Designer rewrites visible .patch source. The searchable Component Palette includes Basic, Choices, Data, Containers, Graphics, Chrome and Nonvisual groups. Graphics contains Picture, Shape and PaintBox; Nonvisual contains Timer and ImageList.

Properties and Events share one Object Inspector. Current layout tools include move/resize, alignment, same size, equal spacing, z-order actions, grid snapping and source-backed Anchors/Dock.

Nonvisual components

Timer and ImageList live in the nonvisual tray and never expose Form geometry or Anchors/Dock. Timer exposes Interval and OnTick. ImageList exposes logical size plus ordered project-resource entries and has no event in Stage 1.

Graphics capability boundary

Picture supports project-resource authoring, Web rendering and current bounded native PNG/JPEG decoding. Shape and PaintBox support Studio authoring plus Standalone Web while current native targets remain fail-closed. ImageList is authoring-only until a real runtime consumer exists.

PaintBox paint handlers are pure drawing handlers; persistent change operations are rejected inside them.

Navigation and shortcuts

Ctrl/Cmd+K opens commands and source symbols. Editor tabs and Project Tree operate on the same v4 project. Structural editors keep their existing keyboard navigation/reorder workflows. Selection, search, caret position and workspace layout are transient IDE state.

Builds

The normal Ready/offline Windows, macOS and Linux path requires no personal GitHub token. Runtime templates are SHA-256 checked before sealing payload v14. FreeBSD remains Console-only via portable C99.

Accessibility boundary

Keyboard/ARIA behavior is covered by automated tests, but manual Narrator, VoiceOver and Orca testing remains a separate validation gate. Patch does not claim WCAG conformance from automation alone.
