Current native boundary

The current desktop line is Native GUI IR 1.6 / payload v16 / runtime v1.7. Native GUI IR 1.5 / payload v15 / runtime v1.6 remains the previous Shape line. It retains Slider through Win32 TRACKBAR, AppKit NSSlider and GTK3 GtkScale, Chrome Stage 1 Panel/Timer/PictureBox/StatusBar, then adds Shape Stage 1 rectangle/rounded/ellipse/line. Native GUI IR 1.4 / payload v14 / runtime v1.5 remains the previous Chrome line. Native GUI IR 1.3 / payload v13 / runtime v1.4 remains the Slider-capable compatibility boundary rather than being silently reinterpreted.

PictureBox note: beta.36 still does not claim complete portable image-source rendering across every project image type and display property. The current v1.7 desktop line already decodes bounded project-resource PNG/JPEG images through Win32/WIC, AppKit/NSImage and GTK/GdkPixbuf under native-picture-formats/1.0. Native WebP/SVG remain deferred and fail closed. Portable fit/aspect/center/opacity behavior on desktop remains an explicit follow-up and fail-closes where unsupported.

Verify a download

Download SHA256SUMS into the same folder as the compiler asset and verify the exact bytes before first use or after replacing a rolling-beta download.

# Linux, or macOS with sha256sum installed
sha256sum -c SHA256SUMS

# macOS built-in tool
shasum -a 256 patch-macos-arm64

# Windows PowerShell
Get-FileHash .\patch-windows-x64.exe -Algorithm SHA256

SHA-256 verifies release-byte consistency. It is not a replacement for Authenticode, Developer ID/notarization or an independent signing authority. Development artifacts remain explicitly unsigned unless a release states otherwise.

Current native Window surface

Windows, macOS and Linux offline linking uses the same current semantic GUI contract as Patch Studio's token-free Ready path. Toolkit interaction remains transient until Patch source performs an explicit change.

  • Slider: finite numeric changed value inside the declared range; native TRACKBAR/NSSlider/GtkScale.
  • Table/Grid: selected row is a transient text-list event value.
  • List-backed ListBox: selected display strings are a transient text-list event value.
  • Menu: separators, portable shortcuts and source-backed Boolean enabled/checked projections.
  • TreeView: selected root-to-node display path is a transient text-list event value.
  • Responsive layout: source-backed Anchor/Dock metadata reflows native controls without creating hidden Patch state.
  • Panel: Stage 1 native visual grouping. Full Delphi-style child-container semantics are not claimed yet.
  • Timer: native scheduling with Patch ticked events.
  • StatusBar: native/status-style text surface, with platform widget differences kept behind the semantic contract.
  • PictureBox: project-resource PNG/JPEG decoding plus the current click path are supported on the v1.6 desktop line under native-picture-formats/1.0; deferred WebP/SVG and richer display properties remain fail-closed.

The offline compiler matrix links and executes canonical responsive, Table, multi-select ListBox, Menu, TreeView, Slider and Chrome Stage 1 Window programs on Windows, Linux, Apple Silicon macOS and Intel macOS before the rolling downloads are published.

Versioned compatibility

The current Ready/offline contract is Native GUI IR 1.6 / payload v16 / runtime v1.7. Native GUI IR 1.5 / payload v15 / runtime v1.6 remains the previous Shape line. Native GUI IR 1.4 / payload v14 / runtime v1.5 remains the previous Chrome line. Native GUI IR 1.3 / payload v13 / runtime v1.4 remains the Slider-capable compatibility line. Native GUI IR 1.2 / payload v12 / runtime v1.3 remains the frozen TreeView line. Older contracts are not redefined: payload v11/runtime v1.2 remains the frozen Menu+list line, v10/v1.1 the persistent-list line, v9/v1.0 the Table line and v8/v0.9 the responsive compatibility line. Explicit legacy linking fails closed when a program requires a newer feature.

How Patch Studio verifies Ready runtimes

The browser path has a separate integrity gate from the self-contained offline compiler. Pages requires studio-runtime-v0.6 plus the three native runtime-v1.7 releases, reads the SHA-256 digest recorded by GitHub for every runtime template, verifies the downloaded bytes and publishes runtime-manifest.json. Patch Studio then re-hashes the selected runtime with Web Crypto before sealing a Ready app.

Platform notes

Windows

The x64 compiler links supported Window projects into a single native Win32 .exe using runtime v1.7.

macOS Apple Silicon

The Apple Silicon download is one standalone compiler binary. Supported Window projects become AppKit .app bundles through runtime v1.7. Development compiler builds are ad-hoc signed, not Developer ID notarized.

macOS Intel

The Intel download is a portable tar.gz kit because the current Node SEA route is not relied upon for macOS x64. The kit includes its own Intel Node runtime and AppKit runtime v1.7.

Linux

The x64 compiler embeds the GTK3 runtime v1.7 linker. Resulting GUI executables still require compatible normal GTK3/system libraries on the target system.

FreeBSD

FreeBSD currently supports Console linking through the portable C99 backend. Native FreeBSD Window/GUI linking is not claimed yet.
