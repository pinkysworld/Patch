Current contracts

Patch Studio uses project bundle v4, Change IR 0.10 and Native GUI IR 1.6 / payload v16 / runtime v1.7 on the current Ready/offline Windows, macOS and Linux line. Project v1-v3 inputs migrate explicitly.

Projects and resources

Project v4 keeps bounded multi-file Patch source plus explicit image resources. The Resource Manager stores logical ids, project-relative paths, media type, size, SHA-256 and canonical project bytes. Current resource types are PNG, JPEG, WebP and SVG. Picture can name a resource and source-backed fit, center, opacity and description. Forms may declare icon "patch-resource:app.icon".

window "Counter" as counter size 520, 360 icon "patch-resource:app.icon":
  picture as logo from "patch-resource:app.logo" fit contain description "Product logo"
  imagelist as toolbar_images size 16, 16:
    image open from "patch-resource:icons.open"
  button "Open" as open_button image toolbar_images.open

Export, Import and Recovery preserve source and resources together.

Design a Window app

Choose a Window example or set Project Type to Window, then add controls from the searchable Component Palette. The Designer rewrites visible .patch source, while Properties and Events share the Object Inspector. Current layout tools include move/resize, alignment, same size, equal spacing, Bring/Send, Move Forward/Backward, grid snapping and source-backed Anchors/Dock. The Form tools can set an optional icon resource; Studio preview shows it in Form chrome.

Designer scrollbars remain visible on scrollable editor, canvas and result surfaces so large Forms and source files do not look clipped.

Tabs and structural Properties

Tabs pages can contain Text, Button, Input, Checkbox, Radio, ComboBox, ListBox, Slider, Table and TreeView directly on that page. Table and TreeView keep their complete source-backed structure when moved, duplicated or edited.

Click Edit beside a nested Table to edit rows and columns. Click Edit beside a nested TreeView to edit hierarchy, labels and node order. These editors call the same source-backed mutations as top-level structural editing.

Runtime event values

Table exposes the selected row as transient list-valued value, represented as a transient text-list of display strings. TreeView exposes the selected root-to-node path as a transient text-list. Toolkit selection itself does not mutate persistent Patch state; source must execute an explicit change to persist it.

Nonvisual components

Timer and ImageList live in the nonvisual tray and never expose Form geometry or Anchors/Dock. Timer exposes Interval and OnTick. ImageList exposes logical size plus ordered project-resource entries and has no event in Stage 1.

Graphics capability boundary

Picture supports project-resource authoring, Web rendering and current bounded native PNG/JPEG decoding under native-picture-formats/1.0. Native WebP/SVG remain deferred. Shape Stage 1 and PaintBox Stage 1 clear/line/rectangle/ellipse/text draw on Studio, Standalone Web and current native Ready/offline Windows, macOS and Linux. PaintBox draw image remains deferred. Buttons bind ImageList items with image list.item on Web; current Native GUI IR 1.6 fail-closes ImageList and Button images. Window icons package as Studio/Web chrome and favicon under window-icon/1.0; current Native GUI IR 1.6 fail-closes Form icons.

PaintBox paint handlers are pure drawing handlers; persistent change operations are rejected inside them. The native PaintBox expression subset is deliberately smaller than general Patch and accepts bounded literals, count inside repeat, and simple number/text/boolean state names; invalid or unsupported state references fail closed.

Navigation and keyboard editing

Ctrl/Cmd+K opens commands and source symbols. The editor tabs and Project Tree operate on the same v4 project. The editor tabs show live Parsed status and caret position from the current source only; this remains transient IDE state.

Structural editors use roving selection. Ctrl/Cmd + Arrow Up/Down reorders the selected item where supported. TreeView additionally uses Ctrl/Cmd + Arrow Left/Right for outdent/indent. Ctrl/Cmd+Enter commits supported inline edits. Escape closes the editor and restores focus without creating application state.

Builds

The normal Ready/offline Windows, macOS and Linux path requires no personal GitHub token. Runtime templates are SHA-256 checked before sealing payload v16. Current native IR 1.6 preserves Table, ListBox, Menu, TreeView, Slider, Chrome Stage 1 and Shape while adding PaintBox Stage 1 clear, line, rectangle, ellipse and text. FreeBSD remains Console-only via portable C99.

Accessibility boundary

Keyboard/ARIA behavior is covered by automated tests, but manual Narrator, VoiceOver and Orca testing remains a separate validation gate. Patch does not claim WCAG conformance from automation alone.
