Beta.27 arithmetic call certificatesExisting formal RangeExpr, wider certificate

Preserve the expression

The concrete certificate now encodes integer literals, variables, addition, subtraction, unary negation and non-negative constant scaling. For bonus + 1, Lean receives a real RangeExpr.add; it does not receive only JavaScript's result.

GeneratedArithmeticCallCertificate.lean is generated from examples/formal-calls-arithmetic.patch and checked under pinned Lean.

Arithmetic direct leaf effect

For amount * 2 with exact amount = 5, Lean re-evaluates the amount to 10, constructs increase [10,10], and checks the existing beta.26 effect-refinement/caller-signature theorem.

Standard Formal CI retains the beta.26 variable certificate and additionally verifies the beta.27 arithmetic certificate.

Exact beta.27 boundaryNo overclaim

Covered

Safe-integer inter-recipe literals/variables, +, -, unary negation and non-negative constant scaling; exact positional binding; interval refinement; one direct quantitative leaf add/remove effect using the same expression fragment.

Still outside

Division, decimals, general variable multiplication, root-program concrete calls, arbitrary structured callee execution, full concrete call traces and production JavaScript/direct-Wasm call equivalence. Patch is not an end-to-end verified compiler.

Earlier call assuranceBeta.25–26

Abstract composition

PatchCalls.lean checks finite rank-decreasing call graphs, argument intervals and callee-to-caller semantic-signature containment.

Exact binding

PatchCallSubstitution.lean, PatchCallRefinement.lean and PatchCallEffect.lean establish exact binding and direct leaf-effect refinement. checkedConcreteBoundEffectRefinesCallerSignature remains the central direct-effect composition theorem.

Semantic Window inputBeta.24

Transient value

Input editing supplies event-local value; the control does not write persistent Patch state.

Explicit commit

Source persists input only through ordinary semantic change. Window preflight supports button clicked and input changed.

Build formats & boundariesNo silent fallbacks

Direct Wasm + portable C99

Direct Wasm lowers the supported numeric Console subset. Raw direct Wasm uses Patch's small host ABI and is not yet a standalone WASI command. Portable C99 is compile/run tested on Linux, macOS and FreeBSD 15.1.

Window targets

Window Web Apps use the generated browser runtime; Windows/macOS/Linux Window packages use the generated desktop player. They are standalone but not yet native AppKit/Win32/GTK widget lowering.
